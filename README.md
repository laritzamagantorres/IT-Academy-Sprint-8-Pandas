# IT-Academy Sprint 8 - Pandas

En este sprint se trabaja con Pandas para explorar, validar, transformar y analizar diferentes conjuntos de datos.

## Contenido

- **Nivel 1:** exploración inicial, validación, limpieza, transformación y análisis descriptivo del dataset de empleados.
- **Nivel 2:** integración de información externa, reestructuración en formato largo, creación de variables derivadas y exportación de resultados.
- **Nivel 3:** generación automática de gráficos según el tipo de variable y desarrollo de una función sencilla para calcular rutas entre ciudades.

## Archivos

- [Sprint_8.ipynb](./Sprint_8.ipynb): cuaderno completo con el desarrollo de los ejercicios.
- [Gráficos](./graficos): gráficos generados automáticamente con el dataset `penguins`.
- [Resultados](./resultados): archivos CSV y Excel exportados por grupo profesional.
